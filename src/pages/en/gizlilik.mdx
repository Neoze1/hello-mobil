# Privacy Policy

Last updated: October 9, 2026. This notice describes the current data flow of the application.

## Stored data

Theme, language, catalog favorites and comparison preferences are stored in localStorage in this browser. Membership details, password hashes, sessions, listings, photos, phone numbers and listing favorites are stored on the server in data/database.json. Session cookies use HttpOnly.

## External services

If the AI key is enabled on the server, search messages and filters are sent to OpenAI; account and seller contact details are not sent. External fonts or images may disclose your IP address to their providers. The demo contact form does not transmit messages.

## Data protection and KVKK

This project is not a certificate of compliance with Turkish data protection law. Before public deployment, a data controller, legal basis, retention periods and request channel must be established. Clearing site data removes browser preferences, not server records. Do not share sensitive information; server records require access control and backups.
